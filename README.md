# 🎮 Simon Says Game

A classic, interactive memory game built completely from scratch using **HTML5**, **CSS3**, and **Vanilla JavaScript**. Test and improve your memory limits with this clean, fully responsive web application.

## ✨ Features
*   **Intuitive Gameplay:** Smooth button animations and distinct audio cues for each color pad.
*   **Dynamic Difficulty:** The sequence grows longer and faster as your score increases.
*   **Responsive Layout:** Fully optimized for mobile, tablet, and desktop viewports.
*   **High Score Tracking:** Keeps track of your best run during your session.

## 🛠️ Tech Stack
*   **HTML5:** Semantic layout structure.
*   **CSS3:** Flexbox/Grid layout, custom transitions, and keyframe flash animations.
*   **JavaScript (ES6):** State management, DOM manipulation, asynchronous timing arrays, and audio synthesis.

## 🕹️ How to Play
1. Click anywhere on the screen or press **Any Key** to begin.
2. Observe the sequence flash displayed by Simon.
3. Repeat the exact pattern by clicking the colored buttons.
4. One wrong click triggers game over! Try to beat your highest score.
